kg-memory now tells you when it changes. Once a day it reads the latest version from PyPI (nothing about the user is sent); when a newer release exists, or the plugin has updated itself ahead of the server, one line at session start says so, at most once a day per project. Notes like this one arrive once after an update. `KG_UPDATE_CHECK=0` in the server's environment turns the daily read off.

Locked nodes: a person can lock a node in the visual editor. A locked node is never archived, and kg_put_node, kg_rename_node and kg_delete_node on it are refused (edges to it still work); if one needs a change, ask the user to unlock it in the editor.
